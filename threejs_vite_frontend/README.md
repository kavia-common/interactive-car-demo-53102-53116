# threejs_vite_frontend

Interactive Three.js car demo built with Vite.

## Run (dev)

```bash
npm install
npm run dev:default
```

Optional: set `VITE_PORT` (already present in `.env`) and run:

```bash
npm run dev
```

## What you should see

- Full-screen 3D canvas with a small footer
- Orbit controls (drag to orbit, scroll to zoom, right-drag to pan)
- A simple car assembled from primitives
- Car moves forward and wraps around; wheels rotate
